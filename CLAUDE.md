## Commands

```bash
npm run dev        # Start dev server at localhost:4321 (runs in workerd with local D1/R2)
npm run build      # Type-check with astro check, then build to ./dist/
npm run preview    # Build and run the production Worker locally with wrangler dev
npm run deploy     # Build and deploy to Cloudflare Workers
npx emdash ...     # EmDash CLI (migrate, secrets, schema, content)
```

## Architecture

Personal blog site built with Astro (`output: "server"` on `@astrojs/cloudflare`) + Tailwind CSS + React, with EmDash CMS for content. Deployed as the Cloudflare Worker `martinnormark-com` on `www.martinnormark.com` (`workers_dev` off). All pages render on demand (the shared layout reads Site Settings and menus from D1 per request), including EmDash routes (`/_emdash/*`).

**EmDash CMS**: Admin at `/_emdash/admin`. Blog posts are the `posts` collection (fields `title`, `excerpt`, `date`, `content` Portable Text; tags via the `tag` taxonomy, exposed as `entry.data.terms.tag[].label`). Content in Cloudflare D1 (binding `DB`), media in R2 (binding `MEDIA`) — binding names are fixed by the EmDash adapters and must match `wrangler.jsonc`. Query with `getEmDashCollection()` / `getEmDashEntry()` from `emdash`; entry types come from the generated `emdash-env.d.ts` (regenerated on dev start, committed). `seed/seed.json` (schema + migrated posts, generated by `scripts/mdx-to-seed.mjs`) is bundled into the Worker: collections auto-apply on a fresh DB, content is imported by the setup wizard ("include content") or locally via `GET /_emdash/api/setup/dev-bypass?content=1` under `astro dev`. `EMDASH_ENCRYPTION_KEY` lives in `.env` locally and as a Worker secret in production. Docs: https://docs.emdashcms.com (llms.txt at /llms.txt).

**Legacy MDX**: `src/content/blog/*.mdx` and `src/content.config.ts` are the migration source only; no page reads them. Remove together with the `@astrojs/mdx` integration once prod content is verified.

**Key Files**:
- `src/layouts/Layout.astro` - Base layout: Site Settings (`getSiteSettings`) for title/tagline/social links, `primary` menu (`getMenu`, hardcoded home/blog fallback), `EmDashHead`/`EmDashBodyStart`/`EmDashBodyEnd` for SEO meta + plugin fragments. Pages pass `title`, `description`, and for entries `content` + `articleMeta`
- `src/pages/search.astro` - Full-text search page using `LiveSearch` from `emdash/ui/search` (theme vars `--emdash-search-*` in `global.css`)
- `src/pages/blog/[slug].astro` - Blog post from EmDash (`getEmDashEntry`, `<PortableText>` with `CodeBlock` override); empty 404 Response renders `404.astro`
- `src/pages/blog/index.astro` - Blog listing from EmDash (`orderBy: { date: "desc" }`)
- `src/components/CodeBlock.astro` - Portable Text `code` block override (no highlighting yet)
- `src/live.config.ts` - EmDash live collection registration
- `src/worker.ts` - Worker entry; wraps Astro handler with EmDash's scheduled handler
- `astro.config.mjs` - Cloudflare adapter, EmDash (d1/r2), MDX with rehype-pretty-code (github-dark theme) and rehype-slug
- `wrangler.jsonc` - Worker name, custom domain route, D1/R2 bindings, cron trigger. Adapter writes the final config to `dist/server/wrangler.json`

**Styling**: Tailwind with @tailwindcss/typography for prose, shadcn/ui color system via CSS variables.
